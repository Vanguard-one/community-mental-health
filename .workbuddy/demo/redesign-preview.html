四、动效体系

移植自 guizang-ppt-skill 的 recipe 体系 —— 每个区块一个语义化配方，不做统一 fade-up

场景 原来 现在 做法
元素进入 简介页整块静止，完全没有入场 品牌区 brand-intro：标识 → 标题逐行 → 描线 → 副标 → 三条特性 → 勾图标 走 hero 档 160ms/step；标题拆成两个 .bt-line 才能逐行升起
滚动触发 切视图时「整页一起 rise」，与滚动无关，滚到时早已播完 每个区块挂 data-reveal，由 IntersectionObserver 按进入视口触发 阈值 0.15 + 底部预留 8%；触发一次即 unobserve；切视图时已在视口内的立即播
悬停交互 只有按钮有 hover 标识微旋 6°、三条特性右移 6px、勾图标放大并提亮 只动 transform / 背景色，都在合成层
语义化配方 所有元素同一动作，延迟 = 下标 × 固定值 页头 90ms 递进 · 卡片依序揭示（y 20→0 + scale .96→1）·
分数弹入 · 统计卡数字滚动计数 · 下划线从左描出 		动作绑在内容语义上；参数照搬 skill 的 rGridReveal / measure-up
降级 — 无 WAAPI 或系统开了「减少动效」→ 引擎不启动，内容静态可读 前置态挂在 .anim-ready 下：类不挂，规则就不成立

⚠️ 动画播完必须 cancel() —— 否则 fill:both 会长期压住元素自身的悬停变换。 另：前置态在 head 里就挂上，避免「先画一帧再淡入」的闪烁。

五、四条硬约束

示例页已按这四条实现，后续写码不得违反

  • ① 新底绝不叠遮罩：alpha 0.06 就会把 text-2 从 5.40 压到 4.95，而底部本来就只有 1.32 的台阶。
  • ② --card-border 不跟着阴影变浅：阴影→5% 后描边是唯一的分层信号。
  • ③ 悬浮提示优先纯 CSS；要用 a-tooltip 必须先真构建看体积（vendor-antd 788.18 / 800 kB）。
  • ④ WebGL 装饰层必须三件套齐全：prefers-reduced-motion 时只画静态一帧；页面不可见停 RAF；无 WebGL 时回退 CSS 静态点阵。另 .auth-card 要加 isolation: isolate，把 screen 混合锁在卡内。
